# Biography pin photos

Place a photo in this directory as `portrait.webp` for the About Andrew pin or `career.webp` for the Work History pin. The site also accepts lowercase `.jpg`, `.jpeg`, and `.png`. Keep one file per slot. When multiple extensions exist, the site picks WebP, JPG, JPEG, then PNG.

Rebuild and deploy to display a new or replaced image. Each photo fills the print window, with its center visible in the crop. For a sharp, small download, export a WebP around 1,000 pixels wide with the subject near the center. An empty slot displays its illustrated photo frame.
