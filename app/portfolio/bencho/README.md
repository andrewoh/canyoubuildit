# Bencho adaptations

These components adapt the free, MIT-licensed [Bencho source](https://github.com/cabralorenzo/bencho) by Lorenzo Cabra, pinned to commit `27ac3159201fa48eb16ef65faa5d8078963a9a61`.

The full upstream copyright and permission notice is retained in [LICENSE](./LICENSE).

| Local component | Upstream source | Portfolio adaptation |
| --- | --- | --- |
| TransportMark | `blocks/step-player/StepPlayer.tsx` | Play/pause geometry for the feed’s preview controls, with native CSS motion |
| ProjectTilt | `blocks/tilt/Tilt.tsx`, `Tilt.css` | Responsive child content, gentler perspective, mouse-only hover, pause and live reduced-motion preferences |
| MagneticFilters | `blocks/magnet-select/MagneticSelect.tsx`, `MagneticSelect.css` | Real category selection, stable readable labels and hit targets, responsive layout |
| PortfolioDock | `blocks/dock/GlassDock.tsx`, `GlassDock.css` | Real section links, active section tracking, keyboard labels and touch support |
| WardrobeCompare | `blocks/image-compare/Compare.tsx`, `Compare.css` | Existing catalog and modeled reference images, labeled keyboard-operable comparison |

The theme maps to this portfolio's moss, ivory, and lime palette. No Bencho brand assets, photography, Pro source, sounds, or global tokens are used. All existing project descriptions and dataset values remain unchanged.
